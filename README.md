# ✨ 2025 Polaroid Recap Generator

A professional, high-performance web tool designed to create aesthetic Polaroid-style achievement posters for the year 2025.

## 🚀 Overview
This project enables users to generate a high-resolution "Year in Review" collage. It features a unique scattered Polaroid stack design with dynamic theme support, ensuring high-fidelity visuals in both dark and light modes.

## 🌟 Key Features
- **Dynamic Aesthetic Design**: Features a scattered Polaroid stack for a modern "Yearly Recap" look.
- **Smart Theme Engine**: Automatically adjusts UI colors and photo filters (brightness/saturation) based on the theme.
- **Real-time Customization**: Includes a live name update feature and instant image previews.
- **High-Resolution Export**: Uses a 3x scaling engine to ensure sharp images for social media sharing.
- **Optimized Rendering**: Resolved common canvas bugs such as text overlapping and visibility issues in light mode.

## 🛠️ Technical Stack
- **Languages**: HTML5, CSS3, JavaScript (ES6+).
- **Framework**: [Tailwind CSS](https://tailwindcss.com/) for utility-first styling.
- **Rendering**: [html2canvas](https://html2canvas.hertzen.com/) for client-side image generation.

## 📂 Quick Start
1. **Clone the Project**: Download or clone this repository to your local machine.
2. **Launch**: Open `index.html` in any modern web browser.
3. **Personalize**:
   - Type your name in the input field (it updates live!).
   - Click on the photo slots to upload 5 of your favorite moments.
4. **Generate**: Click the **"SAVE RECAP TO GALLERY"** button to download your high-res image.

## 🛠️ Developer Notes
The input field is intentionally placed outside the canvas area to ensure a clean capture during the export process. The layout uses Flexbox to prevent text overlapping during high-scale rendering.
